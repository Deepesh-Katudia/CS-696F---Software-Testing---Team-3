# 🧪 CS 696F – Software Testing (Team 3)

## 📘 Project Overview  
This repository contains all deliverables and documentation for **CS 696F – Software Testing**, developed by **Team 3** at Pace University.  
The project follows the full Software Testing Life Cycle (STLC), including **Requirements**, **Test Planning**, **Test Design**, **Test Execution**, and **Final Presentation** phases.

## 🗂️ Repository Structure  

All teams are required to create five main folders as part of the project repository:

📁 CS-696F---Software-Testing---Team-3
│
├── 📂 Requirements
│ └── Contains requirement specifications, user stories, and RCT tables.
│
├── 📂 Test Planning
│ └── Includes test strategy, objectives, scope, and resource allocation.
│
├── 📂 Test Design
│ └── Holds test cases, test data, and traceability matrices.
│
├── 📂 Test Execution
│ └── Contains execution reports, bug logs, and screenshots.
│
└── 📂 Final Presentation
└── Includes final presentation slides and summary documentation.



---

## 🧭 How to Navigate  
- Each folder represents a specific phase of the Software Testing process.  
- Files are organized sequentially for easy tracking of project progress.
